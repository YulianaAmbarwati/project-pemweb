## Fitur
- Routing
- View Blade
- Model
- Database SQLite
- Relasi User & Chirp

## Cara Menjalankan
1. Install dependency
   composer install

2. Copy file .env
   cp .env.example .env

3. Generate key
   php artisan key:generate

4. Jalankan server
   php artisan serve
